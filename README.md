# 미적분학의 본질

3Blue1Brown의 **미적분학의 본질(Essence of Calculus)** 시리즈를 공부하며 정리한 노트입니다.
장면별로 재생되는 그림(자막·식 포함)과 함께, 원문 사이트의 구성을 따라 16장으로 정리했습니다.

**페이지 보기:** https://juhong-park0823.github.io/The-Essence-of-Calculus/

## 구성

- 개요: 장 목록, 한눈에 보기 표, 영상 링크
- 1~16장: 원의 넓이부터 극한, 적분, 테일러 급수, 도함수의 변환 관점까지
- 용어·기호: 노트에 나오는 용어와 기호 모음

## 보는 법

- 각 그림의 ▶를 누르면 설명이 장면별로 재생됩니다. 장면마다 자막 한 줄이 바뀌고, 식이 한 줄씩 쌓입니다.
- ⏮ ⏭, 재생 막대, 장면 점(체크포인트)으로 원하는 장면에 멈춰 볼 수 있습니다.
- 몇몇 핵심 장면에서는 설명하는 영역의 면 색이 부드럽게 깜빡입니다.
- 한 파일(index.html)로 되어 있고 외부 라이브러리 없이 동작합니다. 글꼴은 Pretendard(본문)와 STIX Two Text(수식)를 씁니다.
